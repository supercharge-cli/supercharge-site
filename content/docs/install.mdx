# Install

The installer is served from this site. It downloads the binary from the public GitHub release `iotserver24/supercharge-releases`.

```bash
curl -fsSL https://superchargeai.in/install.sh | bash
```

Pin a release by passing the version to the script:

```bash
curl -fsSL https://superchargeai.in/install.sh | bash -s 1.3.20
```

Windows PowerShell:

```powershell
irm https://superchargeai.in/install.ps1 | iex
```

`1.3.20` is an example of a published tag. Check the releases page for the tag you want. The source checkout these docs follow is 1.3.32, which is newer than that example.

After install, the binary on a typical Linux user path is `~/.local/bin/supercharge`.

Source code is at [github.com/iotserver24/supercharge](https://github.com/iotserver24/supercharge).
