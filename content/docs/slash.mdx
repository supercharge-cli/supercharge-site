# Slash commands

Type `/` in the prompt. The menu fuzzy-matches. A skill with `user-invocable: true` shows up here too. If a skill reuses a built-in name, the built-in keeps that name and the skill is `/plugin-name:command`.

## Session

| Command | What it does |
| --- | --- |
| `/new`, `/clear` | New session. |
| `/resume` | Picker of saved sessions. |
| `/dashboard`, `/sessions`, `/agents-dashboard` | Live roster of sessions in this pager. Hidden in minimal mode. Off with `SUPERCHARGE_AGENT_DASHBOARD=0` or `[dashboard].enabled = false`. |
| `/compact [note]` | Shrink history. Auto-compact also runs near 85% of the context window. |
| `/context` | Breakdown of the context window. |
| `/session-info`, `/status`, `/info` | Auth, model, turns, context. `c` copies the session id. `y` copies the block. |
| `/fork` | Branch history into a new agent. |
| `/rewind`, `/undo` | Drop everything after an earlier turn. |
| `/copy [n] [file]` | Copy the latest reply, or the Nth latest, or write it to a file. A backup is `~/.supercharge/last-copy.txt` (`SUPERCHARGE_COPY_FILE`). |
| `/export` | Export the conversation. |
| `/quit`, `/exit` | Quit. |
| `/home`, `/welcome` | Back to the welcome screen. |
| `/delete` | Delete this session after confirm. |
| `/rename`, `/title` | Rename. `/rename --auto` lets auto-titles resume on Build sessions. |
| `/history` | Fuzzy-search prompts in this session. `↑` on an empty prompt also recalls them. |

## How the agent behaves

| Command | What it does |
| --- | --- |
| `/model`, `/m`, `/models` | List or switch models. Optional effort as a second word. |
| `/effort <level>` | Effort on the current model. |
| `/setup`, `/login` | Provider wizard. |
| `/format` | Switch Chat Completions, Messages, or Responses. |
| `/logout` | Clear session auth. Does not wipe `/setup`. |
| `/always-approve` | Toggle skip-all permission prompts. |
| `/auto` | Toggle Auto-Review. A classifier approves tools it treats as safe. |
| `/plan [text]` | Plan mode. |
| `/new_agent`, `/new-agent` | Create a custom agent in this chat. Paste a full prompt, or let the chat draft it. See [Custom agents](/docs/agents). |
| `/lean` | Switch this chat to the built-in Lean 4 agent (Leancharge). `--lean` on launch does the same. See [Custom agents](/docs/agents#built-in-lean-agent). |
| `/view-plan`, `/show-plan`, `/plan-view` | Preview the saved plan. |
| `/multiline`, `/ml` | Enter inserts a newline. Shift+Enter or Alt+Enter sends. |
| `/compact-mode` | Tighter layout. |
| `/vim-mode` | Vim keys in the scrollback. Saved as `[ui] vim_mode`. |
| `/minimal`, `/fullscreen`, `/full` | Switch screen mode for this session only. |
| `/edit-prompt` | Open `$VISUAL`, then `$EDITOR`, then `vi`. Saving does not send. |
| `/btw <text>` | Side question that does not join the main turn. |
| `/goal <objective>` | Autonomous goal. Also `status`, `pause`, `resume`, `clear`. Optional `--budget <tokens>`. |
| `/loop [interval] <prompt>` | Repeat a prompt. Minimum interval 60 seconds. Jobs expire after 7 days. |
| `/deep-research <query>` | Background research workflow. Watch it with `/workflow runs`. |
| `/workflow [name]` | Launch or manage a workflow: `runs`, `pause`, `resume`, `stop`, `save`. |
| `/workflows` | Catalog of saved workflows. |

Project workflows: `.supercharge/workflows/*.rhai`. User workflows: `~/.supercharge/workflows/*.rhai`.

## Help and maintenance

| Command | What it does |
| --- | --- |
| `/doctor` | Terminal, clipboard, color, input, notification checks. `/doctor fix` lists automatic fixes. Aliases `/terminal-setup`, `/terminal-check`, `/terminal-info`. |
| `/codecov [fix] [scope]` | Local code-quality checks. Runs the project's own coverage tool plus a duplicate-code scan and prints a deterministic report. `fix` re-scans and queues an agent turn for the exact listed gaps. Nothing is uploaded and no tool is installed. |
| `/tutorial`, `/tour`, `/onboarding` | Short onboarding topics. |
| `/docs`, `/howto`, `/guides` | Built-in how-to picker. `/docs <title>` opens one guide. |
| `/release-notes`, `/changelog` | Notes for this version. |
| `/feedback [message]` | Feedback form, or send immediately when you pass text. |
| `/import-claude` | Import permissions, env, MCP, hooks, and paths from `~/.claude`. |
| `/usage`, `/cost` | This session's token totals. Supercharge does not sell credits. |
| `/credits` | Mistral balance popup after Mistral Auth. Other providers do not fill this popup. |
| `/find`, `/jump`, `/timeline` | Fullscreen-only navigation. |
| `/expand` | Minimal mode only. |

`/memory`, `/flush`, and `/dream` are on [Memory](/docs/memory). `/remember` works even when the experimental memory switch is off.

## While a turn is running

| Command | What it does |
| --- | --- |
| `/queue` | List prompts waiting behind the current turn. In the full screen you can also use the queue pane. |
| `/tasks` | List background tasks, subagents, and scheduled jobs. |
| `/recap`, `/summarize` | Summarize where the session is. The summary is a scrollback note. It is not sent back to the model as your next prompt. |
| `/voice` | Dictation into the prompt. Ctrl+Space or F8 starts it. Esc stops. Enter stops and sends. Hold-to-talk needs a terminal that reports key releases. |

## Reading the session

| Command | What it does |
| --- | --- |
| `/transcript`, `/log` | Open the conversation in `$PAGER` (default `less`). The TUI waits until you quit the pager. |
| `/cd [path]` | Dashboard only. Sets the directory new sessions start in. Elsewhere it tells you to open `/dashboard`. |
| `/timestamps` | Show or hide timestamps in the transcript. |
| `/announcements` | Product notices. |
| `/privacy` | What stays on this machine. |
| `/donate` | Open the donate page. |

`/share` is on the menu and currently answers that session sharing is turned off.

## Lookup and toggles

| Command | What it does |
| --- | --- |
| `/help`, `/commands`, `/h` | Open the command palette. Same as Ctrl+P. In minimal mode this is how you browse commands and shortcuts. |
| `/context-window <size>` | Pick a context-window size when the current model advertises more than one. Hidden when there is only one. |
| `/save-tokens [on\|off]` | Shorter replies. Aliases `/pony` and `/ponytail`. |
| `/REA-mode [on\|off]` | Add the reverse-engineering guide to every turn. Aliases `/rea-mode` and `/rea`. |
| `/import-settings` | Open the Claude settings import modal. Alias `/import-claude`. Scans `.claude/settings*.json`, `~/.claude.json`, and `.mcp.json`. Same as Ctrl+I on the welcome screen. Arguments are ignored. |
| `/settings` | Settings modal. Aliases `/config`, `/preferences`, `/prefs`. Type `/` inside the modal to filter. Arguments are ignored. |
| `/toggle-mouse-reporting` | Hand mouse selection back to the terminal, or take it back. Shown only when `[ui] mouse_reporting_toggle = true`. Ctrl+R does the same from the scrollback. |

## Shell session commands

These run in the agent session, including ACP. The pager menu folds hooks and plugins into modals, and these names still work when you type them.

| Command | What it does |
| --- | --- |
| `/hooks-list` | Hooks loaded in this session. |
| `/hooks-trust` | Trust this project so hooks may run. |
| `/hooks-untrust` | Remove that trust. |
| `/hooks-add <path>` | Add a hook file or directory. |
| `/hooks-remove <path>` | Remove that path. |
| `/plugins list` | Installed plugins. |
| `/plugins install <source> [--trust]` | Install. `--trust` trusts it in the same step. |
| `/plugins uninstall <name> [--confirm]` | Remove. `--confirm` skips the extra prompt. |
| `/plugins update [name]` | Update one plugin, or all when the name is omitted. |
| `/plugins reload`, `/reload-plugins` | Read plugins from disk again. |
| `/plugins trust <path>`, `/plugins add <path>`, `/plugins remove <path>` | Trust or attach a local plugin path. |

## Hidden commands

| Command | What it does |
| --- | --- |
| `/debug [scroll\|fps\|log]` | Debug overlays. Listed only on debug builds. A release binary still runs it if you type the name. |
| `/scroll-debug` | Same as `/debug scroll`. Not listed. |
| `/gboom` | Not listed. |
