# Supercharge CLI

Supercharge is a free Rust coding agent you run on your machine. You pay the model provider you connect in `/setup`. There is no Supercharge subscription and no credit balance.

The agent calls itself Supercharge AI, built by R3AP3R Editz. It is a terminal UI over your repo: it reads files, runs shell commands, edits code, and can call tools you add.

## Start here

1. [Install](/docs/install) the binary.
2. Run `supercharge` in a project.
3. Run `/setup` and save a provider. Details are on [Provider setup](/docs/setup).
4. Type a task and press Enter. Approve tools, or turn on always-approve when you mean to.

## Where everything lives

| Path | What it is |
| --- | --- |
| `~/.local/bin/supercharge` | Usual install location. `sc` is a second name for the same binary when the installer created that link. |
| `~/.supercharge/config.toml` | Provider, models, UI, and feature settings. |
| `~/.supercharge/sessions/` | Saved conversations. |
| `~/.supercharge/memories/` | Curated notes: `USER.md` and `MEMORY.md`. |
| `~/.supercharge/docs/user-guide/` | Built-in guides copied on launch. `/docs` opens them inside the TUI. |

`SUPERCHARGE_HOME` moves that whole directory. `SUPERCHARGE_BIN_DIR` moves only the install location.
