# Supercharge CLI

Supercharge is a free Rust coding agent you run yourself. You pay only the model provider you connect in `/setup`. There is no Supercharge subscription and no credit balance.

The agent identifies itself as Supercharge AI, built by R3AP3R Editz.

## What you get

- An interactive terminal session in the repo you open.
- An Agent Client Protocol WebSocket with `supercharge agent serve`.
- An HTTP inbox with `supercharge agent daemon`, so thin clients never launch the CLI.
- Curated notes under `~/.supercharge/memories/`.
- The same agent inside an E2B sandbox when you publish that template.
